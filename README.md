Designed and implemented a cloud-native microservices platform using .NET 8 Web API, Python FastAPI, and Microsoft Azure. The solution includes Orders, Inventory, and Analytics microservices, containerized using Docker and deployed on Azure Kubernetes Service (AKS).

Implemented Istio/Envoy Gateway for service ingress and traffic management, with Azure API Management (APIM) as the external API gateway for centralized routing, OAuth 2.0/JWT authentication, and backend integration.

Key technologies and capabilities:

Backend: C#, ASP.NET Core Web API, Python, FastAPI, REST APIs.

Cloud & Containers: Azure AKS, Azure Container Registry (ACR), Docker, Kubernetes.

API Management & Networking: Azure APIM, Istio, Envoy Gateway, service-to-service communication.

Security: Microsoft Entra ID, OAuth 2.0, JWT validation, Azure Managed Identity.

Data: PostgreSQL, Azure SQL, database integration and secure connectivity.

DevOps: Git, GitHub, CI/CD pipeline implementation planned using GitHub Actions.

Architecture: Microservices, container orchestration, API gateway pattern, cloud-native deployment, and centralized API security.

The project demonstrates end-to-end implementation of a secure, scalable, and cloud-ready microservices architecture on Azure
